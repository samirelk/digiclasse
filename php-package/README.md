# حزمة منظومة مدرستي الذكية (PHP 8.2 & MySQL)
## DigiClasse - Smart Attendance & WhatsApp Cloud API Package

هذه هي الحزمة البرمجية الكاملة المخصصة للبيع والتسليم للمؤسسات التعليمية الراغبة في التثبيت الذاتي (Self-Host) على استضافاتها أو خوادمها الخاصة (cPanel, VPS, Local Server).

### محتويات الحزمة:
1. `database.sql`: مخطط قاعدة بيانات MySQL المتكاملة لجميع الجداول (المؤسسة، المستخدمين، الأقسام، التلاميذ، المقاعد، الغياب بالدقائق، وسجلات واتساب).
2. `config.php`: ملف الربط مع قاعدة البيانات و Meta WhatsApp Cloud API.
3. `whatsapp_api.php`: وحدة إرسال رسائل وإشعارات واتساب الفورية بالصيغة الدولية لأولياء الأمور.
4. `install.php`: معالج التثبيت التلقائي لمعلومات الاستضافة وقاعدة البيانات.

### متطلبات التشغيل:
- PHP 8.1 أو أحدث (PHP 8.2+ موصى به)
- تفعيل ملحقات: `pdo_mysql`, `curl`, `json`, `mbstring`
- MySQL 5.7+ أو MariaDB 10.3+
- حساب Meta for Developers مع تصريح WhatsApp Cloud API مفعل
